Учёт затрат

Личное приложение (Telegram-бот) для учёта затрат. Используется только владельцем.

Политика конфиденциальности / Privacy Policy

Приложение получает доступ к Google-аккаунту только для чтения и записи данных учёта затрат владельца. Данные не передаются третьим лицам, не продаются и не используются для рекламы. Доступ можно отозвать в любой момент: https://myaccount.google.com/permissions

The app accesses Google user data only to read and write the owner's expense records. Data is not shared with third parties, sold, or used for advertising. Access can be revoked at any time: https://myaccount.google.com/permissions
